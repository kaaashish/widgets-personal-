## widgets-personal-
widgets for ur computer (windows)

🦌
hi i like making widgets for my computer. this is just a repository of all of them, unless i want to start splitting them up!

🛠️
all of these widgets are built with Electron.js which is a framework that lets you build desktop apps using HTML, CSS and JavaScript. it basically turns web pages into real desktop windows, which means i can make cute little widgets that sit on my screen!

how to run
1. make sure [Node.js](https://nodejs.org/) is installed on your computer
2. clone or download this repo
3. open the widget folder you want in a terminal (e.g. `cd garden-widget`)
4. run: `npm install`
5. run: `npx electron .`

## garden-widget
a cosy deer-themed trio — a to-do list, a focus timer, and an hourly day planner, all running together. soft browns and pinks, dancing script font, and a little deer that reacts to what you're doing (thinking, locked in, adding a task, or having an oopsy) 🦌🩷
